# 山间溪流：统一场景实现

配色：纸白 #ffffff、墨黑 #17201f、溪蓝 #b2cbd0、苔绿 #74846b、纸船 #f3eddc。
字体：保留苹方与系统中文无衬线；标题稍加字距，正文轻灰。
布局：上方左侧文字、右侧水湾；河流沿左侧向下，文章先于作品。
核心：小猫、纸船、水湾与出水口必须来自同一幅画，不再拼贴独立猫图。

使用确认图生成无文字背景层。固定比例的源头、可续接的中游、独立河口形成三个区域；中游随真实内容高度重复，不拉长小猫或山石。文字、文章链接和项目仍为 DOM。保留原型数量控制但折叠显示，默认画面以还原图为主。现有基础版本保留供对比。

审查：不新增装饰卡片或额外配色。背景只服务一条贯穿页面的山溪，保持右侧阅读空间。动态效果克制，不对整幅插画做漂移。

## 验证与限制

桌面测试 2 篇 / 1 作品时高度 1577px、4 段；12 篇 / 3 作品时高度 4769px、12 段。手机 390px 宽度验证无横向溢出。具体数字随视窗和文案长度改变。

此版以还原插画为优先，水湾仅叠加轻微涟漪；不使用旧版 WebGL 覆盖细致的石头与水纹。旧 WebGL 河道仍可在实验设置中切回。小船随阅读位置移动。中游复用同一组河段，长页面会重复出现景物，并非程序生成无限不同的地形。

目前条目数量按钮为布局测试，真实内容来源仍是 Markdown；后续正式首页应直接传入筛选后的文章 / 作品列表，而非复制演示条目。

## 2026-09-09 河宽调整

沿用现有色彩与字体，不重新生成素材。中游和下游横向占幅改为原来的 70%，阅读小船同步调整位置和大小；源头 430–600 区间平滑收窄，小猫与纸船所在区域不压缩。正文起点由约 30% 改为 23%。场景取消 1440px 上限，宽度随容器变化，不设置固定的溪流最小像素宽度。

2560px 与 320px 视窗检查均无横向溢出；宽屏主区域左边界为 0，宽度覆盖扣除滚动条后的可用视窗。此次为图片显示布局变形，不是独立河岸建模。
