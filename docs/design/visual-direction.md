# 折光：个人网站 UI/UX 视觉方向

## 阶段

设计稿包含首页、文章列表、作品列表三张高保真概念图。2026-09-07 已基于首页第三版完成 Next.js 首页 V1；文章、作品仍处于设计阶段。

首页 V1 已实现真实 DOM 标题、SVG 头像、GSAP 逐字入场，以及独立玻璃纹理的 WebGL 轻微形变／鼠标响应。玻璃不是实时三维建模或物理折射。静态图片是降级路径。桌面 1280×720 已查看浏览器截图；390×844、320×700 已检查元素边界，无横向溢出；浏览器无错误或警告，键盘焦点可显示未开放栏目提示。减少动态效果与无 WebGL 降级目前为代码检查，尚未通过浏览器模拟这两种环境。

## 设计原则与自查

个人网站的主体是作者与内容。记忆点集中在一个带虹彩的自由形态玻璃雕塑，形态兼具液滴与弯折书页的联想，不沿用旧站的规则圆环。
首页遵守已有要求：Header + 主视觉。第三版使用已认可的 slogan“让想法，慢慢成形。”，改为左上单行并放大；不覆盖玻璃，没有额外简介、小字、编号、底部入口或促销模块。
文章按阅读信息组织，作品按视觉展示组织，不把三页都做成同一套卡片。
自查调整：取消模板式角落英文标签、装饰网格、无意义的 01/02 编号；把色彩限制在材料反射中，背景不使用彩色渐变。

## Tokens

- Void `#000000`：整体背景。
- White `#F7F8FA`：主文字和高光。
- Quiet `#A2A6AF`：时间、摘要等辅助信息。
- Cobalt `#356BFF`：玻璃内部折射。
- Ice `#8CE8F2`：边缘高光。
- Orchid `#C17EFF`：局部色散。
- 字体意图：英文 Manrope（中等字重、干净几何结构），中文 Noto Sans SC；正文常规字重。落地时确认字体许可与字体加载体积。
- 桌面：约 1440 × 1000 视觉画布，左右 72px 安全留白，Header 高约 88px。没有浏览器外壳、设备模型或大圆角页面边框。
- 字号：首页 slogan 桌面约 60–64px、常规字重、单行，字距约 0.02em，实际以设计图视觉比例校准；栏目标题约 56–64px；文章标题约 25–30px；正文 16–18px；日期约 13–14px。
- 正文保持合理行宽；元信息对比度需实测，不使用难以辨认的极暗灰色。

## 页面与布局

首页：小头像在左，首页／文章／作品在右；slogan 左对齐，位于画布约 6% 横向、24% 纵向处。玻璃保留在中央偏右，文字与雕塑彼此避让。头像暂用 assets/avatar-placeholder.svg 的通用线稿，不代表用户真实外貌；后续直接换照片。

```text
头像                                     首页  文章  作品

让想法，慢慢成形。
                          自由形态玻璃

```

文章：同一 Header；左侧标题“文章”与一行有意义的说明；全部／设计／开发／随笔筛选；一篇大幅精选文章与带日期、题目、摘要的阅读列表。缩略图为内容服务，不让每篇文章都用玻璃装饰。

作品：同一 Header；“作品”标题与简短说明；大幅主项目和两张次级项目形成非等高排布。卡片配图像项目真实截图或设计研究，不把作品页做成纯抽象画廊。沿用已有 story-web、GitHub 内容工作流等主题，图中补充内容均为视觉占位，不声称已有成果或统计。

## 交互计划

- 导航：位置跨页保持一致，当前栏目用白色与短下划线标识，键盘焦点清晰。
- 首页：玻璃柔和形变与慢速转动；鼠标在主视觉内移动时轻微改变倾斜与反光。限制幅度，避免大范围跟随、抢占滚动或挡住导航。
- Slogan：参考 Rolling Letters 的逐字滚入，首页 V1 已自行实现同类机制：入场一次后静止。研究见 rolling-letters-research.md；没有复制未取得的第三方源码。
- 切页：导航持续稳定，内容短暂淡入；不使用长时间遮罩、加载倒计时或自定义鼠标替换系统指针。
- 文章：标签点击过滤，标题点击进入正文；悬停只改变标题亮度或图片轻微曝光，不移动整列内容。空筛选提供重置入口。
- 作品：图片悬停轻微放大并显示打开线索；点击进入详情。没有仅悬停才能发现的必要信息。
- 手机：Header 保留三个直接入口，雕塑整体缩放，slogan 不裁切、不遮挡玻璃；文章、作品切单列，点击区域至少 44px。
- 无 WebGL、低性能设备或 prefers-reduced-motion：显示同构图静态主视觉；暂停后台标签动画。
