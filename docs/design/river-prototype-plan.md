# 自适应河流原型

独立路由 /river-prototype/，不替换现有首页。提供 2/6/12 篇文章和 1/3 个作品的演示切换；复制内容明确标记为演示，不写入内容库。

配色：纸白 #ffffff、墨灰 #2d3432、水蓝 #b8d7df、水深 #7faab9、浅岸 #e7efeb、纸船 #f8eed6。沿用当前黑体标题与正文。

布局：紧凑 Header → 原型控制栏 → 猫咪首屏 → 最近文章 → 作品 → 页尾。河流占用独立左侧空间，不覆盖内容；移动端收窄但仍可辨认。

技术：测量实际文章/作品 DOM 锚点；每个新增锚点生成一个连续贝塞尔河段，不纵向拉伸整图。ResizeObserver + 数量变更重新测量，滚动仅更新船的位置。水彩感先采用分层透明描边与固定尺寸纹理，避免长页面巨大滤镜。纸船用可缩放的多折面 SVG，船头沿切线旋转。船的位置按视窗阅读高度映射到河道，不按整页比例跳跃。

此原型验证布局、增长、朝向和响应式；不是最终水彩美术版本。相比模拟图减少河岸石草，优先验证文章可读性。减少动态效果时船保留静态位置。

## 浏览器验收

- 2 篇 / 1 作品：7 河段；12 篇 / 1 作品：17 河段；12 篇 / 3 作品：19 河段。
- 桌面实测长页面 6,185px；小船随滚动移动到当前阅读位置，转向角度读取成功。
- 390px 手机 6 篇 / 3 作品：13 河段，页面 6,104px，无横向溢出。
- 从长页切回 2 篇 / 1 作品后，河道恢复 7 段；控制栏始终可访问。
- 浏览器错误与警告日志为空。减少动态效果支持由代码实现，未通过系统设置切换测试。
- 河流绘制使用统一路径叠层，消除河段端点重复叠色。几何生成只发生在布局变化时，滚动只定位船。
