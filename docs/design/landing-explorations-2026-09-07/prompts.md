# 个人网站：五种长页面概念设计

生成方式：内置 imagegen，五个独立的新图生成请求。此轮仅设计探索，不修改网站代码。所有作品名、文章标题和图中日期均为概念占位内容，不代表已经完成或发布的项目。

每张展示一个桌面首页从首屏到作品、文章的滚动长页面。静态图不包含可运行交互，以下为后续实现方向。

| 方向 | 图片 | 拟实现交互 |
| --- | --- | --- |
| 光的建筑 | 01-light-architecture.png | 鼠标轻移带动光影视差；滚动时建筑图缓慢展开。 |
| 蓝色实验室 | 02-blue-playground.png | 拖拽蓝色环带旋转；实验作品悬停切换形态。 |
| 暗场引力 | 03-dark-orbit.png | 鼠标吸引银色线束；滚动切换作品景别。 |
| 自然档案 | 04-living-archive.png | 移动放大镜观察叶脉；内容地图节点悬停展开。 |
| 红色编辑部 | 05-vermilion-editorial.png | 滚动驱动纸张折叠；项目以翻页方式衔接。 |

这些是交互设计提案，落实时需平衡性能、触摸操作和减少动态效果偏好。
