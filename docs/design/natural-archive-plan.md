# 自然档案：首页还原方案
## 目标
以用户选定的自然档案长图为视觉依据，还原白底、绿色宋体、巨大银杏叶、作品关系图和慢读的节奏。不是把整页截图当网站：真实文字可选中，链接与交互可用。只替换现有首页 UI／不再引用的线上资产，保留 content、Git 历史、设计原稿和其他本地资料。

## 设计约束
- 颜色：纸白 #ffffff；深叶绿 #243d25；苔绿 #3f6849；正文灰 #747870；细线 #e7e9e3。
- 标题：本地宋体／Noto Serif SC 回退；正文与导航为简洁中文无衬线。大字不加粗，不插入营销标签。
- Header：紧凑 76px（手机 64px），姓名左侧，首页／文章／作品右侧，绿色小圆点标识当前位置。
- 首屏：左上两行“把好奇，／种进生活。”；右侧叶片主视觉占约 60%，下方留呼吸空间。
- 作品：左侧“数字花园”简介；右侧水彩底的真实节点图，“正在生长的作品”作为图上方标题，不重复放一个整屏标题。
- 慢读：左侧日光阅读静物，右侧文章入口。下方“拾起一些片刻”列出现有仓库文章。
- Footer：一句“持续生长，不必着急。”，无多余链接墙。

布局：Header → [标题 | 银杏叶放大镜] → [数字花园简介 | 标题 + 作品图] → [阅读照片 | 慢读入口] → 文章列表 → Footer。
每个断点调整空间比例，不把桌面长图压成手机截图。

## 素材先行
内置 imagegen 从获批图提取并细化三份独立资产：清晰银杏叶白底摄影、无字无节点深绿水彩、阅读静物照片。图中不烘焙标题／放大镜／交互标识。
源图保存 docs/design/assets/natural-archive；部署用适当尺寸 WebP，首屏叶片预加载，下方素材懒加载。不会把插值放大冒称新增细节。

## 放大镜
同一高清图作两个同步图层：底层 blur 约 1.5–2px，圆形上层无 blur 并放大约 1.8 倍。
圆心跟随指针，放大图平移满足镜片中心对应原图同一坐标，避免鼠标越移动越偏。
Pointer Events + requestAnimationFrame 更新 CSS 变量，不每帧 React setState，无持续空转动画。
离开隐藏；键盘聚焦后用方向键移动、Escape 收起；触摸按住观察，保留纵向滚动，pointercancel 正常清理。
默认提供一处静态示意镜片让用户发现交互。减少动态效果时移除缓动但保留放大功能。

## 内容与可用性
作品图的真实项目节点对应 content/works；其余细枝仅为装饰，不伪造几十个作品。点击／键盘可查看真实项目介绍与源码入口。
文章使用现有 content/articles 元数据和正文，不将设计图生成的标题日期作为用户真实成果。
本轮导航指向首页的作品与文章锚点，并随滚动更新 active；完整独立文章栏目不作无效链接占位。
阅读入口进入现有文章的静态详情页；作品节点同样进入真实作品介绍页，避免“查看”按钮无响应。尚未增加独立栏目列表页，首页导航使用分区锚点。

## 验收
- 桌面与手机截图对照：标题、叶片、作品、慢读区域比例与留白。
- 鼠标实际移动确认镜片跟随且清晰；键盘、边缘坐标、触摸降级。
- 页面无横向溢出，图片无失败，Header active 与滚动一致。
- lint、TypeScript、静态构建、根路径和 /story-web 路径导出资源检查。
- 记录与参考的合理差异：重新生成的照片非逐像素相同；图和文章使用真实数据。
