# 2.5D 水彩河流对照版

保留白底、墨灰文字、灰蓝水面、灰绿岸边和象牙纸船。既有内容布局不变，河流保留独立左侧空间。

在 /river-prototype/ 加入“基础 / 水彩 2.5D”模式切换。水彩纹理沿河道弧长映射到三角带网格，WebGL 片元着色器做双层流动、局部折射扰动、细波光和船尾波。可变河宽和柔软透明边缘改善规则管道感。零新增运行时依赖。

固定视窗大小的 Canvas，长页不创建整页高分辨率画布。页面离开视窗、浏览器隐藏或减少动态效果时停止连续动画。无 WebGL / 纹理加载失败时保留静态水彩 SVG。原有首页不替换。

岸边精绘素材少量点缀，手机缩小。此版非物理流体模拟，也不是完整 3D 场景；真实感来自纹理、流向、岸边层次与局部光影。
