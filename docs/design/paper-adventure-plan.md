# 纸上冒险 · 实现方向

## 视觉约束

- 纸白 #ffffff、墨灰 #2d3432、苔绿 #6f8b76、杏黄 #e6b657、水蓝 #91b7c2、辅助灰 #68716d。
- 标题用系统中文黑体的中粗字重，正文用苹方 / 微软雅黑；不引入大宋体或科技界面元素。
- 左对齐的文字和右侧精绘纸船猫组成首屏。下方依次为最近文章、唯一精选作品 Story Forge、简短页脚。
- 一条 SVG 贝塞尔细线从纸船附近蜿蜒到正文左侧。细线不作为背景图片的一部分，固定描边宽度，跟随真实版面尺寸。
- 猫咪回应指针轻微倾斜；沿线的小纸船跟随滚动。减少动态效果时关闭运动，触屏不拦截滚动。

布局：Header → [标题 / 猫咪纸船] → [细线 / 文章列表] → [细线 / Story Forge] → Footer。

保留手绘猫、纸船、水彩和游走细线的识别度；文章前置，只展示一个真实项目，不用虚构数量填充版面。Story Forge 依据公开 README 介绍为桌面优先编程 Agent 平台；架构展示明确为项目结构示意，并非产品截图。
