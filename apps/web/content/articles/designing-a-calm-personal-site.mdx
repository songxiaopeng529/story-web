“极简”很容易被误解成白底、黑字和大量留白。真正决定页面是否安静的，并不是颜色数量，而是注意力有没有清晰顺序：先看到我是谁，再知道我做过什么，最后决定要不要继续阅读。

## 先建立阅读节奏

首页同时承担简历和入口的职责，因此每一屏只回答一个主要问题：

1. **我是谁**：名字、方向和一句足够具体的自我描述。
2. **我在做什么**：时间线、当前项目和工作方式。
3. **我如何思考**：文章与作品作为证据，而不是装饰性的卡片墙。
4. **如何继续联系**：只保留真实、愿意公开维护的入口。

<Callout type="tip" title="留白不是空白">
  留白负责分组和停顿。它应该随着信息层级变化，而不是给所有模块套用同一个巨大间距。
</Callout>

## 黑白也需要层次

纯黑和纯白的强对比适合标题，却不适合承载整页正文。更稳定的做法是先定义语义色，再让组件只使用这些令牌：

```css
:root {
  --background: #f7f7f5;
  --foreground: #111111;
  --muted: #6f6f6b;
  --line: #d8d8d2;
  --surface: #ffffff;
}
```

这组颜色并不试图制造“品牌色”。它的目标是让正文、辅助信息、边界和可交互区域在不同屏幕上仍然容易区分。

| 层级     | 主要手段             | 避免              |
| -------- | -------------------- | ----------------- |
| 页面标题 | 字号、字重、紧凑行高 | 额外阴影和渐变    |
| 正文     | 舒适行长、稳定段距   | 过浅灰色          |
| 辅助信息 | 字号与语义灰         | 只靠透明度区分    |
| 交互状态 | 下划线、边框、位移   | 只在 hover 时可见 |

## 动效要解释状态

开屏动画可以建立第一印象，但它不应该成为每次访问的收费站。这里采用三个约束：

- 同一个浏览会话只完整播放一次。
- 始终提供跳过入口，键盘也能触达。
- 系统开启“减少动态效果”时，直接呈现最终状态。

```ts
const shouldAnimate =
  !window.matchMedia("(prefers-reduced-motion: reduce)").matches &&
  sessionStorage.getItem("intro-seen") !== "true";
```

页面里的普通过渡尽量交给 CSS。只有当多个元素需要明确的时间线编排时，才值得引入额外的动画运行时。

## 把限制变成风格

黑白、少导航、少动效并不等于缺少个性。相反，稳定的排版比例、细致的边界、诚实的文案和可预测的交互，会逐渐形成更耐看的识别度。

这个网站还会持续调整，但判断标准保持不变：如果一个视觉元素不能帮助阅读、定位或理解，它就需要重新证明自己为什么存在。
